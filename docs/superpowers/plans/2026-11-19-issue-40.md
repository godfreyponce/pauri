> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pointing at the paperclip, mic, send/stop orb, model name, effort bars, history trash can, and the two chips (and their Remove buttons) shows a label drawn by #34's `HoverLabel`. Today these controls use `.help`, which never shows. Bottom-row and chip labels show above the control. No label is cut off at the panel's edge.

**Architecture:** `HoverLabel` (`Sources/Pauri/PanelView.swift:312`) gets three changes. An `above` flag puts the tip over the control. The tip wraps to the panel's inner width. The tip slides sideways to stay inside the panel. It finds the panel through a named coordinate space that `PanelView` sets. Then each listed `.help` call becomes `.modifier(HoverLabel(...))`, except the menu items in `ModelPicker.swift:42`, which keep `.help`.

**Tech Stack:** Swift 6, SwiftPM, SwiftUI, macOS 14 (`Package.swift`).

**Spec:** issue #40, plus the owner's comment on it and the owner's gate 1 answers below (no design spec).

- [ ] **Step 1: Name `PanelView`'s coordinate space**

Directly after `.padding(12)` (`PanelView.swift:220`), add `.coordinateSpace(.named(HoverLabel.space))`. It goes before `.overlay { HistoryList }`, so the history list's trash tip is measured against the same space. That space covers the whole panel content, in content points, inside `ZoomedContent`'s scale.

- [ ] **Step 2: Rewrite `HoverLabel`'s body**

Keep `text`, `pinned`, and `isHovered`. Add `var above = false`, `static let space = "panel"`, and `static let margin: CGFloat = 12`. Keep `pinned` in the doc comment, and add a line saying the tip sits under the view, or over it with `above`, and moves sideways to stay inside the panel.

Placement, without measuring the tip in `@State`, so nothing jumps on the first frame:

- **Panel room.** On `content`, add `.onGeometryChange(for: Room.self)`. It returns the control's width and `proxy.bounds(of: .named(Self.space)) ?? .infinite`, which is the panel's rect in the control's own coordinates. Store the result in `@State private var room`. `Room` is a private `Equatable` struct `{ width: CGFloat; panel: CGRect }`.
- **Wrap width.** The tip view (today's `Text` chain, with `.fixedSize()` replaced by `.lineLimit(6)` and `.fixedSize(horizontal: false, vertical: true)`) goes inside a small private `Layout`. Name it `TipWidth(width:)`. It proposes `ProposedViewSize(width: width, height: nil)` to its one subview in both `sizeThatFits` and `placeSubviews`, and it reports the subview's size. The width is `room.panel.width - 2 * Self.margin`. That way a short tip stays one line at its own width, and a long tip wraps at the panel's inner width.
- **Position.** `.overlay(alignment: .topLeading)`. On the `TipWidth` view, set two alignment guides from its own size `d`:
  - `.alignmentGuide(.top) { d in above ? d.height + 4 : -22 }`
  - `.alignmentGuide(.leading) { d in -x(d.width) }`, where `x(tip) = min(max(room.width - tip, room.panel.minX + margin), room.panel.maxX - margin - tip)`. The start value `room.width - tip` is today's trailing alignment, and the clamp keeps the tip inside.

  Keep the `if isHovered || pinned` and `.allowsHitTesting(false)`.
